# איך מעדכנים את האתר

אין צורך לגעת בקוד. כל התוכן יושב בשני מקומות:

| מה | איפה |
|---|---|
| טקסטים ומספרים | `src/data/*.ts` |
| תמונות מקור (גדולות, לא עולות ל-GitHub) | `images-source/` |
| תמונות מוכנות לאתר (נוצרות אוטומטית) | `public/images/` |
| לוגואים | `public/brand/` |
| מודלים תלת-ממדיים | `public/models/` (ראו [models.md](models.md)) |

## מפת קבצי הטקסט

| קובץ | עמוד |
|---|---|
| `home.ts` | דף הבית: הכותרת, "מי אנחנו", ציר היעדים, "מה הלאה" |
| `about.ts` | מי אנחנו, ציר הזמן |
| `race.ts` | המספרים של המרוץ (הקפות, ק״מ, אנרגיה...) |
| `belgium.ts` | הסיפור של בלגיה: פרקים, תמונות, תוצאות, טבלת הקבוצות, ניתוח המרוץ |
| `projects.ts` | הפרויקטים (השמשות) |
| `teams.ts` | חמשת הצוותים |
| `gallery.ts` | אירועי הגלריה, תיוג ותיאורים |
| `sponsors.ts` | ספונסרים |
| `join.ts` | עמוד ההצטרפות והטופס |
| `tasks.ts` | עמוד המשימות למצטרפים (/tasks) |
| `parts.ts` | רכיבי "פרקו את אורנע" |
| `site.ts` | שם, פרטי קשר, תפריט |

בקבצים האלה עורכים רק את מה שבין המירכאות `'...'`. לא מוחקים פסיקים וסוגריים.

## שלוש דרכים לעבוד

**1. הכי פשוט: אומרים ל-Claude.** כותבים בצ'אט מה לשנות ("בפרק הרישום בבלגיה תחליף את הטקסט ל...", "הוספתי 5 תמונות לתיקייה X, תכניס אותן לפרק Y"). Claude מעדכן, בודק ודוחף.

**2. מחליפים קבצים בתיקייה ומספרים ל-Claude.** מכניסים תמונות או מחליפים קבצים, ואומרים רק "שיניתי ב-images-source/story". Claude מריץ את ההמרה ומחבר.

**3. לבד, בלי Claude.** עורכים קובץ ב-`src/data/`, מריצים `npm run dev` כדי לראות, ואז `git add`, `git commit`, `git push`.

## החלפת תמונות בסיפור של בלגיה

כל פרק ב-`belgium.ts` מפנה לתמונות לפי שם, בלי סיומת, למשל `'story/race-rain'`. זה הקובץ `images-source/story/race-rain.jpg`.

**להחליף תמונה קיימת:** שומרים את התמונה החדשה **באותו שם בדיוק** בתוך `images-source/story/` (דורסים את הישנה), ומריצים `npm run images`. לא צריך לגעת בטקסט.

**להוסיף תמונה לפרק:** שמים קובץ חדש ב-`images-source/story/` עם שם באנגלית, בלי רווחים (למשל `race-finish.jpg`), מריצים `npm run images`, ומוסיפים לפרק ב-`belgium.ts` שורה:

```ts
{ src: 'story/race-finish', alt: 'תיאור קצר של מה רואים בתמונה' },
```

השמות הקיימים בתיקייה, לפי פרק:

| פרק | קבצים |
|---|---|
| האריזה | `projects/shipping-truck` |
| הרישום | `story/registration-camp`, `story/registration-night` |
| בדיקות סטטיות | `story/static-car`, `story/static-open` |
| בדיקות דינמיות | `story/dynamic-pitlane` |
| מרוץ 24 השעות | `story/race-pitlane`, `story/race-rain`, `story/race-telemetry` |
| מה היה קשה | `story/race-night-repair` |
| בדרך הביתה | `story/packing-crate` |

טיפים: JPG או PNG (לא HEIC של אייפון; באייפון: הגדרות ← מצלמה ← תבניות ← "התאמה מרבית"). לרוחב, 2000 פיקסלים ומעלה. אין צורך להקטין: `npm run images` מקטין, דוחס ומוחק נתוני GPS.

## גלריה

שמים תמונות בתיקייה `images-source/gallery/<מספר-שם>/`, למשל `7-ecomotion`, מריצים `npm run images`, ומוסיפים את האירוע ל-`galleryEvents` ב-`gallery.ts` (או אומרים ל-Claude).
