# איך האתר עובד: המחשב, GitHub ו-Vercel

בקצרה: **המחשב** הוא המקום שבו עורכים. **GitHub** הוא הארכיון שמחזיק את הקוד וכל ההיסטוריה שלו. **Vercel** לוקח את הקוד מ-GitHub, בונה ממנו אתר ומגיש אותו לגולשים.

```
 המחשב שלנו  ──git push──▶  GitHub  ──אוטומטי──▶  Vercel  ──▶  הגולשים
 (עריכה)                    (ארכיון קוד)          (בנייה ואירוח)
```

## 1. התיקייה במחשב

`C:\Users\User\Documents\מועדון רכב\אתר` היא עותק עבודה. כאן עורכים טקסטים, מוסיפים תמונות ובודקים את האתר מקומית (`npm run dev`). שום דבר שעושים כאן לא משפיע על האתר החי עד שדוחפים.

חלק מהתיקייה **לא** עולה ל-GitHub, בכוונה (מוגדר בקובץ `.gitignore`): תמונות המקור הגדולות, קבצי SolidWorks, וקבצי ביניים.

## 2. GitHub

המאגר: https://github.com/AfekaRacing/afeka-racing-site, בחשבון של המועדון.

- כל שינוי נשמר כ-commit: מי שינה, מתי, ומה בדיוק. אפשר לחזור לכל גרסה קודמת.
- `git push` שולח את השינויים מהמחשב ל-GitHub.
- אם המחשב הולך לאיבוד, הכול נמצא ב-GitHub. מורידים מחדש עם `git clone` וממשיכים.
- מוסיפים חברים חדשים דרך **Settings → Collaborators**. כשמישהו עוזב, מוציאים אותו משם.

## 3. Vercel

Vercel מחובר למאגר. בכל פעם שמשהו מגיע ל-`main` ב-GitHub:

1. Vercel מוריד את הקוד, מריץ `npm run build` ומקבל תיקייה של קבצים סטטיים (HTML, JS, תמונות).
2. אם הבנייה הצליחה, הגרסה החדשה עולה לאוויר תוך כדקה, בכתובת https://afeka-racing-site.vercel.app.
3. אם הבנייה נכשלה, **האתר הקודם נשאר באוויר** ולא נשבר. השגיאה מופיעה בלוח הבקרה של Vercel.
4. כל הגרסאות הקודמות נשמרות. אם משהו השתבש, בלוח הבקרה ← **Deployments** ← גרסה קודמת ← **Promote to Production**, וחוזרים אחורה בלחיצה.

## למה אין פה סיכון

- **אתר סטטי.** אין שרת, אין מסד נתונים ואין התחברות משתמשים, אז אין מה לפרוץ אליו או לשבור.
- **אין מידע אישי באתר.** לא מופיעים שמות של חברי צוות, ומהתמונות נמחקים נתוני מיקום (GPS).
- **הטופס לא שומר כלום אצלנו.** הפרטים נשלחים ישירות ל-Google Form של המועדון, כמו שהיה עד היום.
- **אין סיסמאות או מפתחות בקוד.** אין במאגר שום פרט סודי.
- **חינם.** GitHub ו-Vercel בתוכניות החינמיות, שלא דורשות כרטיס אשראי.
- **הבעלות אצל המועדון.** הכול רשום על החשבון AfekaRacing, לא על סטודנט מסוים, כך שהמחזור הבא ממשיך מאותו מקום.
- **HTTPS אוטומטי.** Vercel מספק חיבור מאובטח בלי הגדרות.

## אם אפקה רוצה דומיין משלה

למשל `racing.afeka.ac.il`: ב-Vercel ← **Settings → Domains** ← מוסיפים את הכתובת. Vercel מציג רשומת DNS אחת (CNAME), ומחלקת המחשוב של אפקה מוסיפה אותה. שום דבר אחר לא משתנה.
